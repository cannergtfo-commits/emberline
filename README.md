# Emberline

Fun hot-seat multiplayer. Pass one phone or tablet around the table. Two to four players, five banners, no accounts and no online lobby.

Banners: Nordmark, the Vael Synod, Heartland, Mawbrood, and the Aure Choir.

## Branches

- `browser` — wide-screen build. Menus and the battle panel are laid out for a desktop browser. This branch stays as that version.
- `mobile` — touch build for phones and tablets. Big targets, a thumb rail for orders, and a map that stays usable in portrait and landscape.

Gameplay, units, and maps are the same on both branches.

## Android

The mobile build is on [Blazar Apps](https://blazarforce.net/blazar-apps.html) as Emberline 1.0. Android asks before the install.
